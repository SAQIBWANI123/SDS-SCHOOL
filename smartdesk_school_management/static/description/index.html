User guide

From installation to your first report card in seven steps.

1
Install
Copy the smartdesk_school_management folder into your addons path, restart Odoo, enable Developer mode, then Apps → Update Apps List and install CampusPulse.
2
Open the app
The default Administrator user is added to the School Administrator group automatically. Other users: Settings → Users → School access rights.
3
Configure once
Configuration menu: Academic Years & Terms, Grade Levels (with subjects), Grading Scale, Fee Categories. Then create Classes & Sections and Teachers.
4
Admit and enrol
Receive applications from the website form or create them in Students & Parents → Admissions. Approve & Enrol creates the student.
5
Bill and collect
Create a Fee Structure per grade, then School Fees → Generate Fees. Open a statement and use Register Payment.
6
Run the school day
Take attendance (Mark All Present → fix exceptions → Submit), publish notices, record conduct.
7
Exams & year-end
Create an exam → Start Exam → Generate Report Cards → enter marks → Mark Completed. At year-end use Promote Students.

Upgrading from version 1.x

Safe, in-place, tested on Odoo 19.

Version 19.0.2.0.0 upgrades in place from 1.x — the technical name smartdesk_school_management is unchanged.

  • ✓Back up your database, replace the module folder and run odoo-bin -u smartdesk_school_management -d YOURDB.
  • ✓Students with the old Promoted status are moved to Enrolled automatically.
  • ✓Existing fees, payments recorded as “amount paid”, attendance, exams and library data are kept.
  • ✓Hostel data tables are not deleted by the upgrade. Drop school_hostel_* tables manually if you no longer need them.
